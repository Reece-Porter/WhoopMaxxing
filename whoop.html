One-click sync setup

The button triggers the Whoop sync GitHub workflow straight from this page. It needs a fine-grained GitHub token that can only run Actions on this repo: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → Only select repositories → your WhoopMaxxing repo → Repository permissions → Actions: Read and write → Generate, then paste it here.
