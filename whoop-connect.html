Connect Whoop

One-time setup, browser only — nothing to install. Your password and secrets never touch this page; it only builds the official Whoop login link.

Step 0 — prerequisites (once)

1. Create an app at developer.whoop.com with redirect URI exactly http://localhost:8789/callback and scopes read:recovery, read:sleep, read:cycles, read:profile, offline.

2. In your GitHub repo → Settings → Secrets and variables → Actions, add three secrets: WHOOP_CLIENT_ID, WHOOP_CLIENT_SECRET (both from the Whoop app page) and WHOOP_TOKEN_KEY (make up any long random password — it encrypts your token).

Step 1 — log in to Whoop

Approve access. You'll then land on a broken localhost page — that's expected.

Step 2 — paste the URL you landed on

Copy the full address from the browser bar (it starts with http://localhost:8789/callback?code=…) and paste it here:

Step 3 — run the "Whoop authorise" workflow

In your repo: Actions tab → Whoop authorise → Run workflow, paste the same URL into the box and run it. Do this within a few minutes — codes expire fast. The workflow swaps the code for a token on GitHub's servers, stores it encrypted, and runs your first sync. After that, syncing is automatic every 3 hours.
